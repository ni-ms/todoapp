# Reclaim review and Daymark scope

Reviewed October 15, 2026 using Reclaim's current official product and 2.0 help pages. The legacy 1.0 help page is explicitly marked legacy and should not be treated as the current task workflow.

Sources: [Planner](https://reclaim.ai/features/planner), [2.0 features](https://help.reclaim.ai/en/collections/19768177-features), [Tasks](https://help.reclaim.ai/en/articles/16558552-tasks-overview-decide-what-to-work-on-when), [Chat](https://help.reclaim.ai/en/articles/17124965-reclaim-chat-overview-ai-assistant-for-your-calendar).

Reclaim combines a calendar planner, natural-language chat with preview/approval, priorities, adaptable focus time and routines, buffers, meeting coordination, scheduling links, and connected calendars. Its current task workflow can recommend relevant tasks during protected work sessions rather than always making a separate event per task. This differs from the earlier task-blocking-centric workflow.

| Capability | Daymark now | Still needed for broader parity |
| --- | --- | --- |
| Natural-language task capture | Local text/voice → editable drafts, selected text/code context | Conversational follow-ups and broader document formats |
| Daily planning | Clear schedule and due/in-progress list | Personalized daily recommendations |
| Task scheduling | Local seven-day preview, deadlines/priority/effort, busy-time avoidance, breaks, apply/undo | Continuous flexible rescheduling, explicit locks, richer availability and dependencies |
| Focus/routines | Manually created events and planned task sessions | Recurring adaptable focus goals and habits |
| Calendar integration | Local week/day/month, ICS export, outward Google publishing | Import busy time and two-way conflict resolution; Outlook |
| Meetings | Manual events | Smart recurring meetings and booking links |
| Context | Explicit local file/folder excerpts, user-reviewed | PDFs/Office parsing and optional persistent retrieval |
| Learning focus | Course/project/career tags and local contextual capture | Learning feedback, spaced review, syllabus dependencies and validated outcomes |

The implementation deliberately keeps **task definitions and calendar sessions separate**. Local language models propose task details; a deterministic planner finds time. File excerpts do not become executable agent instructions. Proposed changes remain reviewable.

For a student who also codes and prepares for a tech career, the most useful next steps are imported busy time, flexible study sessions, prerequisites, and spaced retrieval. Team meeting automation is a lower priority. A defensible learning advantage remains a hypothesis requiring evidence from actual learner outcomes; local processing and file context alone do not establish a moat.
